Demonstration Website & Security Audit

*Demonstration report using a fictional Montréal café (North Star Café). No client relationship implied.

Observation: The homepage introduces the café but does not immediately guide mobile visitors on what step to take next (e.g., view menu, order online, or get directions).

Recommendation: Add 3 tap-friendly action buttons immediately beneath the hero banner: [View Menu], [Get Directions], and [Order Online].

Observation: The physical address and phone number only exist at the footer. Mobile customers looking for opening hours leave before finding them.

Recommendation: Place tap-to-call phone links and operating hours right beneath the hero section on mobile screens.

Observation: The copy states "Great coffee and good food," which is generic and lacks local customer trust signals.

Recommendation: Replace generic statements with specific local highlights, recent Google review badges, and dietary/vegan options.

Observation: Certain menu items and contact forms remain in English even when the French toggle is active, creating friction for Montréal visitors.

Recommendation: Complete 100% translation symmetry across menus, checkout links, and contact confirmation states.

Observation: A publicly accessible .env.bak file was detected in the web root containing exposed third-party API tokens.

Recommendation: Immediately revoke exposed keys, remove public config backup files, and add .env* to web server access block rules.

This audit evaluated the North Star Café website for mobile clarity, customer conversion, bilingual completeness, and basic security hygiene.

Tested Devices: iPhone 14 Chrome, Android Pixel 7, Desktop Edge
Total Findings: 5 (3 High, 2 Medium)
1. Primary Call-to-Action Missing Above Fold (High)

2. Unclickable Phone Number (High)
Phone number is rendered inside a static image. Fix: Convert to standard tel: HTML link.
3. Incomplete French Localization (Medium)
Checkout options revert to English. Fix: Ensure full i18n translation coverage across checkout modals.
4. Publicly Exposed Backup Configuration File (Security Critical)
Extracted exposed Stripe API test key in public web folder. Fix: Delete server backups and restrict .env access.
